# Real maritime video source references (original videos not bundled)

The application supports preparing **two distinct original Pexels videos** after you download them on your own computer:

1. **Ferry silhouettes with cargo vessel on the horizon** by **Rahime Gül**, Pexels video **28945771**: https://www.pexels.com/video/silhouettes-on-ferry-with-cargo-ship-view-28945771/
2. **Pilot boat sailing alongside cargo ship** by **Alexander Grigorian**, Pexels video **7397246**: https://www.pexels.com/video/a-boat-sailing-alongside-a-cargo-ship-7397246/

The Pexels licence permits modifications and use subject to terms: https://www.pexels.com/license/

Open each page and select **Free download**. The application never claims to download clips or verify clip authenticity. Follow **Help → Video sources & limits** or [`docs/GUI_HELP_AND_REAL_FOOTAGE.md`](../docs/GUI_HELP_AND_REAL_FOOTAGE.md).

Processed local video outputs live in `build/real_maritime_clips/` (not committed). Each output includes a provenance JSON and clearly discloses synthetic shake injected into real video frames for controlled verification. Neither original MP4 has been included in this package or generated in the assistant environment.
